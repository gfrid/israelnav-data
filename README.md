# IsraelNav HD lane data

Pre-built HD road data for Israel used by the IsraelNav prototype app: lane markings, road surfaces, junctions, bridges and ramps, tunnels, traffic-light and sign placement, and road markings. It's stored as vector tiles in a single MBTiles file.

Each **release** has:
- `israel_lanes.mbtiles`: the data (MBTiles, vector tiles z13–z16)
- `manifest.json`: `{version, url, size, sha256}`, read by the app to download and check updates

The app reads `https://github.com/gfrid/israelnav-data/releases/latest/download/manifest.json`.

## Source and licence

Derived from **OpenStreetMap** data, © OpenStreetMap contributors, available under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). This derived database is likewise made available under the ODbL.

Most geometry is **generated by rules** (lane offsets, exit lanes, gores, bridge ramps, pole placement) and marked `INFERRED` or `UNKNOWN`. It is **not** survey-accurate and must not be used as authoritative lane guidance.
